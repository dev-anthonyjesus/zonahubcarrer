Como o ZONA distribuiu o edital
A quantidade de questões de cada matéria influencia a frequência no plano.
Lógica do plano
O algoritmo ajusta a semana conforme os dados disponíveis.
1. Peso do edital
Mais questões = mais exposição.
2. Desempenho
Matérias com menor acerto recebem reforço.
3. Alternância
Teoria, questões e revisão se alternam.
4. Gamificação
Check concluído = LIBS + progresso.
